# contact

cosmic farmland is one person, not a company, so there is no support queue and
no sales team. the fastest way to reach anything here is github.

## the code

- [github.com/marshallhouston](https://github.com/marshallhouston) is the profile
  that owns every repo linked from this site.
- [cosmic-farmland](https://github.com/marshallhouston/cosmic-farmland) holds the
  claude code plugins catalogued in the toolshed: skills, slash commands and
  hooks.
- [cosmicfarmland-index](https://github.com/marshallhouston/cosmicfarmland-index)
  is this site itself, including the data files behind the app cards.

## how to raise something

open an issue on the repo the thing lives in. bugs in an app go to that app's
repo, which is linked from its card on the home page and from
[llms.txt](/llms.txt). bugs in a skill or command go to the cosmic-farmland
repo. bugs in the site itself, including anything wrong in the generated catalog
or the machine-readable files, go to cosmicfarmland-index.

pull requests are welcome on any of them. these are personal projects tended in
spare hours, so a reply is not instant, but issues do get read.
