the same instrument that tells you a star is mostly hydrogen tells you a leaf is mostly chlorophyll. one physics, one answer, no scale change. that collapse is the whole idea. below, nine live apps read off the same detector.

wavelength / nanometres reference lamp: Hg, He, Na, H

Toolshed

the instrument that does the reading. claude code skills, commands, and plugins, all source-visible.

Slit

7 commands narrow a whole messy repo state down to one beam you can actually measure. /ship, /next, /handoff.

Grating

20 skills split that beam into its parts. each one knows how to separate one thing from everything next to it.

Detector

4 plugins record it. installed and enabled separately, by cadence, so nothing you are not using is running.
