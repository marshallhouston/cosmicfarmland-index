# Critique log

One file per critic run: `passN.md` (or `passN-<variant>.md` when a pass judged
several pages). Paste the critic's full reply, gap list and the closing
`SCORE: X/10` line, under a heading naming what was screenshotted.

Runs before pass 8 were not saved. What survives of them is only what the owner
carried into TASTE.md, which is binding regardless of what any critic said.
